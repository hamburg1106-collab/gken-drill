# G検定 1問1答

G検定の4択問題を解説つきで回す学習アプリ。スマホで片手で回すことを前提にしている。

公開URL: https://hamburg1106-collab.github.io/gken-drill/

## できること

- 全200問の4択問題。解答すると即座に正誤と解説が出る
- 解説は「なぜ正解か」に加えて、**選ばなかった3つの選択肢が何の用語なのか**も1行ずつ載せる
- 10問1セット。終わると正解数と誤答一覧が出て、間違えた問題だけやり直せる
- 「間違えた問題だけ」モード。直近で誤答した問題が対象で、正解すると自動で外れる
- 出題は未出題の問題を優先。一周して既出から出す段階でも、直前のセットの問題は避け、
  間違えたままの問題と解答回数の少ない問題から先に出す
- 分野別の到達度バー。どの分野が手つかずか一目で分かる
- オフライン動作（PWA）。ホーム画面に追加すれば全画面で開く

## ⚠ 要確認マークについて

年号・数値・法令名など、記憶違いが混入しやすい要素を含む問題には `needsCheck: true` を立て、
画面上に「⚠ 要確認」と表示している（全45問）。この印の問題は公式テキストとの照合を推奨する。

## 問題の追加・修正

問題は `src/data/questions/` 配下に分野ごとのTypeScriptファイルとして置いてある。

```ts
{
  id: 'm19',              // 分野の頭文字 + 連番。既存IDは変えない（学習記録が紐づく）
  category: 'ml',
  text: '問題文',
  answer: 0,              // choices の何番目が正解か
  needsCheck: true,       // 任意。年号・数値を含むなら立てる
  choices: [
    { text: '選択肢', note: '正解なら理由、不正解ならその用語の説明' },
    // 4つ
  ],
}
```

選択肢は画面上で毎回シャッフルされるので、`choices` の並び順に意味はない。
追加したら `src/data/index.ts` の結合対象に入っているか確認する（分野ファイル単位で取り込み済み）。

## 学習記録

正誤の記録はブラウザの localStorage（キー `gken-drill/progress/v1`）にのみ保存される。
サーバーには何も送らない。端末をまたいだ同期はしない。ホーム画面下部からリセットできる。

## 開発

```bash
npm install
npm run dev      # 開発サーバ
npm run build    # 型チェック + 本番ビルド
npm run lint     # oxlint
npm run icons    # public/ のアイコンを再生成
```

main ブランチへの push で GitHub Actions が走り、GitHub Pages へ自動デプロイされる。
